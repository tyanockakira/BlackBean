# BLACK BEAN — правила разработки

## Контекст

BLACK BEAN — демонстрационный full-stack сайт сети из трёх specialty-кофеен в Киеве. Интерфейс, пользовательские тексты, SEO-метаданные и демонстрационные данные — только на украинском языке. Общение и технические документы команды — на русском. Названия переменных, функций, компонентов и git-коммитов — на английском.

## Стек и структура

- React + Vite, React Router, Motion, Lucide React.
- Supabase/PostgreSQL — источник данных после подключения backend-этапа.
- Cloudflare Turnstile, Vercel, Oxlint.
- `components` — UI; `pages` — маршруты; `features` — сценарии; `lib` — интеграции; `styles` — глобальные стили; `supabase` — миграции и политики; `tests` — проверки.

Не усложнять архитектуру без конкретной потребности. Не добавлять мультиязычность, внешние сервисы или зависимости без согласования.

## Дизайн и UX

Urban Specialty × Editorial Minimalism. Цвета: молочный `#F5F2E9`, графитовый `#191919`, кобальтовый `#2455D6`, белый `#FFFFFF`, нейтральный `#B8B4AA`. Шрифты: Manrope и IBM Plex Mono с кириллицей. Использовать асимметрию, крупную типографику, оптимизированные изображения и SVG-иконки Lucide. Эмодзи запрещены. Адаптивность начинается с 320 px.

Каждый интерактивный элемент должен иметь видимый focus, понятное украинское имя и корректную семантику. Учитывать `prefers-reduced-motion`.

## Безопасность и данные

- Цены, состав заказа, наличие и бонусы проверяются сервером; клиент не является источником истины.
- RLS обязательна для пользовательских и административных данных.
- Заказ защищается проверкой владельца и допустимых переходов статуса.
- Начисление 5% после выполнения заказа и списание бонусов до 30% выполняются атомарно.
- Персональные данные не хранить в `localStorage`.
- Не хранить секреты, не менять production-базу и не подключать production-сервисы без запроса.

## MVP

Главная, меню, три кофейни, информация о бренде, ассортимент и наличие, конструктор, корзина, предзаказ с оплатой при получении, авторизация, история и повтор заказа, бонусная программа и админ-панель.

Вне MVP: доставка, онлайн-оплата, SMS, кассовые интеграции, мультиязычность и мобильное приложение.

До отдельного запроса не делать полноценные страницы, backend, базу данных, внешние подключения, commit, push или deploy.

## Проверки

Перед передачей изменений запускать `npm run lint` и `npm run build`. Не заявлять об успешной проверке, если команда не запускалась.
